## Detailed Description
CareCenter for Codex is a specialized, local Windows system tray and CLI utility for the Codex desktop environment. The application helps identify and safely clean up hung background processes, stale lockfiles, and stuck Microsoft Store states — fully offline, without telemetry, and without any cloud dependencies.

### Key Features:
- **Codex Startup Diagnosis:** Detects blocked startup paths, stale lockfiles, and hung helper processes.
- **Safe Process Cleanup:** Terminate orphaned background processes conservatively without data loss.
- **SQLite Database Maintenance:** Maintains the local Codex log database with automated backups, integrity checks, WAL checkpoints, `PRAGMA optimize`, and `VACUUM`.
- **Microsoft Store Assistance:** Troubleshoots Store-related package issues via built-in repair and reset paths.
- **Transparent Auditing:** Every maintenance and repair action is logged locally for full accountability.
- **Automation Guard:** Built-in safeguards prevent interventions while active tasks are running.

### Design & Accessibility:
- Lightweight Windows system tray utility with quick access to all functions
- Clean, high-contrast interface with accessible elements and descriptive tooltips
- Fully offline-first: 100% zero-egress, no telemetry, no remote server communication
